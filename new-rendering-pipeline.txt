
!!! WILL REQUIRE COMPLETE REWORK OF ENTITY, DRAWABLE, CAMERA, RENDERING PIPELINE AND WINDOWING SYSTEM !!!

Scene:
- contains a list of drawables, camera's, entities etc

    Rendering:
        renders each camera

Drawables:
    On Enable:
        registers itself to the scene as a drawable

    Rendering:
        renders itself using the rendering pipeline on the GPU

Camera:
- contains a buffer to render on (e.g. backbuffer, filestream)

    On Enable:
        registers itself to the scene as a camera

    Rendering:
        renders all drawables in the Scene to the buffer



Window:
- Graphics Context -> OpenGL BackBuffer for rendering on the display



a frame:

game    fixed-update
window  update
    window  process-events

!!!
game    update
    if camera enabled: register camera for rendering
    if camera disabled: unregister camera for rendering

    if drawable enabled: register drawable for rendering
    if drawable disabled: unregister drawable for rendering
game    render
    for each camera:
        check if rendercontext valid
        enable rendercontext
        render camera POV
